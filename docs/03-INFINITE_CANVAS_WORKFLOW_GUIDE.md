# 无限画布（Infinite Canvas `/studio/`）多模态连线与 AI 导演工作台实战手册

无限画布（`/studio/`）将 **Meta Muse 全系多模态能力** 与 **16 套电影学/开源导演预设 + 7 套视觉画风 + 全球 24 大开源导演 Skills 库** 融合为可视化节点连线工作流，并同时向画布内的 Seedance、Veo、Kling、Wan、Grok 等全系视频模型开放同款导演技法赋能。

---

## 一、画布节点分类与 Muse 模型矩阵映射

画布已针对创作体验完成精准能力归类与自动过滤（自动隐藏非创作类的 `muse-invite` 与纯转写 `muse-asr`）：

| 画布节点类型 | 可选 Muse 模型 | 核心画布交互特性 |
| :--- | :--- | :--- |
| **文本节点 (Text)** | `muse-chat`、`muse-agent`、`muse-audio`、`muse-live` | 支持多模态连线识图、云端沙盒代码执行（`muse-agent`）；当上游连入**音频节点**时，自动组装 `input_audio` 供 `muse-audio` / `muse-live` 听音作答并返回可点击播放的语音回复链接 |
| **图片节点 (Image)** | `muse-image` | 原生比例直出（`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`）最高 2K WebP 无水印图像；自动识别真实 `image/webp` MIME，最多支持连入 **4 张参考图** 进行人设/场景一致性改图 |
| **音频节点 (Audio)** | `muse-tts`、`muse-podcast` | `muse-tts` 秒级合成多音色角色台词；`muse-podcast` 走异步任务管线并展示实时 `0→100%` 进度条，支持 **自动 / 30s / 60s / 180s** 时长档位与双人/多人播客风格指令 |
| **视频节点 (Video)** | `muse-video`、`muse-video-20s ~ 60s`、`muse-director` | 原生走 JSON 顶层媒体协议（绝不误入 `metadata.content`）；支持最多 **6 张参考图**、**首尾帧**、**源视频续写**、**「生成声音」开关（`mute_voice`）** 与 **AI 导演预设工作台** |

## 二、四大高频黄金连线工作流

### 工作流 1：多角色锁脸锁服装的 10s~60s 连续剧情视频
1. 新建 2~3 个 **图片节点（`muse-image`）**，生成主角三视图设定单、反派设定单与主场景概念图。
2. 新建 **视频节点**，按目标时长选择 `muse-video`（`1~10s`）或 `muse-video-20s / 30s / 40s / 50s / 60s`。
3. 从上述图片节点拖出连线连接到视频节点：
   - **角色/场景参考（`reference`）**：最多可连 **6 张图**，画布自动放入 JSON 顶层 `images[]` 数组，跨 6 段视频全程锁死角色五官与服饰；
   - **首帧 / 尾帧（`first_frame` / `last_frame`）**：可将特定关键帧连线标记为首帧（`first_image_url`）或尾帧（`last_image_url`）。
4. 点击视频节点提示词栏上的 **🎬 场记板图标（`Clapperboard`）** 打开导演工作台，一键勾选画风与导演转场技能，点击生成即可。

### 工作流 2：AI 漫剧 / 短剧全自动导演（`muse-director`）
1. 新建 **文本节点** 编写单集剧本/分镜大纲，并准备 1~4 个角色设定 **图片节点**。
2. 将文本节点与角色图片节点全部连线至一个切换为 **`muse-director`** 的视频节点（时长滑块范围 `10–90s`）。
   - *智能兼容*：切换到 `muse-director` 时，若连线上原本带有 `first_frame` / `last_frame` 标记，画布会自动将其折叠合并入顶层 `images[]` 参考图列表，防止任何设定图丢失；
   - *长轮询保障*：画布对 `muse-director` 自动将前端轮询窗口放宽至 **`25 分钟（600 次轮询）`**，并支持后台标签页完成后无缝回填画布节点。

### 工作流 3：基于已有视频节点的无缝接力续写（`video_url`）
1. 选中画布上已生成完毕的一段视频节点（例如 `5s` 或 `10s` 的开场镜头，文件 `≤20MB`）。
2. 从该视频节点拉出连线至新的 **视频节点**，选择 `muse-video-20s` ~ `muse-video-60s` 档位。
3. **前端零成本防呆校验**：源视频时长必须小于「目标档位上限 - 1 秒」（例如 `muse-video-20s` 要求源视频 `< 19s`，`muse-video-30s` 要求 `< 29s`）。若超限，画布会在本地直接弹窗提示拦截，**0 网络请求、0 预扣费**。

### 工作流 4：人物保留口型但静音、方便后期贴中文/多语种配音（`mute_voice`）
1. 打开视频节点的设置面板（Popover），找到 **「生成声音」** 开关（默认开启，直出带人声与音效的 MP4）。
2. 若希望后期自行挂载第三方精修配音，关闭「生成声音」开关：画布自动向 Muse 视频模型发送顶层 `"mute_voice": true`——成片画面中角色依然配合剧情自然张嘴表演，但人声对白轨被干净剥离，同时**完整保留刀剑碰撞、脚步、海浪风声等环境音效（SFX/Foley）与背景音乐（BGM）**。

## 三、「AI 导演预设与全球 24 大开源 Skills 库」工作台使用指南

可通过以下 **3 个入口** 随时唤起交互式导演工作台弹窗（`DirectorSkillsModal`）：
- 画布视频节点底部提示词栏的 **`Clapperboard`（🎬）图标按钮**；
- 视频节点设置面板内的 **「16预设 & 24开源库」** 入口按钮；
- 独立视频创作台（`/video`）顶部工具栏的 **「导演预设 & 开源Skills」** 按钮。

### 三大核心页签功能
1. **Tab 1 — 16 套导演与转场技能（`skill_preset`，支持多选叠加）**：
   - 顶部提供 **5 套黄金导演组合**（`🔥爆款短剧3秒钩子`、`⚔️东方仙侠变速打戏`、`🎬精品漫剧全流程连戏`、`🛍️商业TVC微距流体`、`🎞️王家卫框景长镜头`），点击即可一键配齐最佳画风 + 多项技能组合；
   - 下方网格展示 **6 套开源导演蒸馏预设（⑩–⑮）** 与 **9 套电影学经典运镜预设（①–⑨）** 及 `RAW` 原样模式，支持任意勾选叠加（实时在节点胶囊显示如 `720p · 16:9 · 20s · 🎬3项导演技能`），每张卡片均附带样片预览与可点击的 GitHub 开源仓库协议署名。
2. **Tab 2 — 7 套视觉画风锁（`style_preset` + `custom_style`）**：
   - 一键锁定 `真人电影感`、`2D 动漫赛璐璐`、`3D 国漫修仙`、`欧美暗黑漫剧`、`赛博霓虹科幻`、`电商种草实拍` 或 `原样直传`，并可叠加自定义色调/胶片补充描述。
3. **Tab 3 — 全球 24 大开源导演 Skills 仓库导航**：
   - 支持按 7 大制片领域分类筛选与关键词检索，一键跳转 GitHub 原仓，或直接点击 **「套用推荐预设 + 插入代表性分镜模板」** 将工业级分镜写法填入当前节点。
4. **左侧边栏离线秒开提示词库**：
   - 打开画布左侧边栏 **「提示词」** 页签（或节点 `BookOpen` 提示词弹窗），首位默认展开 `AI 影视/短剧/漫剧开源导演 Skills 库`，内置 **50 条** 黄金组合、导演技能与开源仓库分镜模板，离线零延迟即点即用。

### 跨模型导演技法自动赋能机制
- 当节点选择 **`muse-*` 系列视频模型** 时：画布在 `POST /v1/videos` JSON 顶层原生发送 `style_preset`、`custom_style`、`skill_preset`、`custom_skill`，保持用户原始 `prompt` 干净不重复；
- 当节点选择 **非 Muse 视频模型**（如 `seedance-2.0/2.5`、`flow-omni`、`flow-veo`、`kling-v3`、`wan3.0-video`、`grok-video`）时：画布前端自动将所选画风与多项导演技能的专业英文/中文镜头调度指令拼合注入 `prompt`，让全画布所有视频模型都能共享这套开源导演工程体系！
